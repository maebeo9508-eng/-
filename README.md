# 현장도면 · 물량 집계

건설 현장에서 휴대폰으로 평면도를 그리고 벽·바닥·천장 면적, 다루끼·석고 자재, 문·창문, 전기·설비·가구 수량과
배관 길이를 자동으로 집계하는 앱입니다. 안목·벽 중심·바깥 치수를 한 번에 넣고, 3D로 돌려 볼 수 있습니다.

두 가지 모드가 있습니다 (화면 왼쪽 위에서 바꿈, 도면마다 저장).

- **인테리어 도면**: 벽·방·문·창문·전기·설비·가구를 그리고 자재 물량을 집계합니다. 가구 36가지(거실·침실·주방·욕실·사무·상가·장식)를
  그림을 보고 골라 놓고, 방마다 바닥 모양(마루·타일·대리석·카펫 등 14가지)과 벽지 색을 고르면 평면이 컬러 평면도가 되고 3D에도 보입니다.
  3D에서 방 안을 걸어서 둘러보고, 밤으로 바꾸면 조명이 켜집니다. 예시: 원룸, 아파트(방 2·거실·주방·욕실), 카페 매장.
  방마다 벽 마감(실크·합지 벽지, 페인트, 벽 타일)과 천장 마감을 고르면 **마감 자재**가 자동으로 나옵니다:
  벽지 롤 수, 페인트 리터(통 수), 마루 박스, 타일 장 수, 장판 길이. 1롤 면적·로스(%) 같은 기준은 ‘자재 기준’에서 고칩니다.
- **조감도 (행사·경기)**: 텐트·무대·좌석·장비·현수막·사람·건물·나무에 축구장·농구장·관람석·시상대 같은 운동 경기 시설까지
  90가지 물건을 그림을 보고 골라 놓습니다. 평면에도 물건이 색 그림으로 보이고, 고른 물건은 손잡이를 끌거나 아래 막대의
  버튼으로 바로 돌리고(15°) 크기를 바꾸고 복제하고 같은 간격으로 줄 세울 수 있습니다.
  잔디·아스팔트·모래·인조 잔디·코트 바닥을 칠하고, 동선을 그려 통로 폭 안에 걸리는 곳을 찾습니다(동선 체크).
  현수막·백월·벽보·건물 앞면·부스 뒷벽에는 글자나 사진을 넣고, 벽은 색을 바꾸거나 사진을 붙일 수 있습니다.
  3D 조감도(하늘·그림자·바닥 재질, 낮·오후·노을·밤)로 보고, 입구부터 사람 눈높이로 걸어서 둘러보고, 큰 그림으로 저장합니다.
  의자 배열에는 **좌석 번호**(A1, A2 … 무대 쪽이 A열)가 붙고 좌석표 CSV로 내보내며, 관람·대기 구역을 표시하면 **수용 인원**을 어림합니다.
  예시: 야외 기념식, 실내 세미나, 축구 대회(운동장), 야외 축제(광장), 실내 체육관, 웨딩·연회장, 전시회.

두 모드 모두 **견적**을 낼 수 있습니다: 집계 탭의 ‘견적’에서 줄마다 단가를 넣으면 금액·공급가액·부가세·합계(한글 금액)가 계산되고,
인건비 같은 기타 항목(할인은 ‘-’)을 더해 견적서(PDF)·CSV로 저장합니다. 넣은 단가는 기기의 **단가표**에 기억되어 다음 도면에도 들어가고,
단가표는 고치기·지우기·CSV로 내보내기/불러오기로 다른 폰·PC와 같이 쓸 수 있습니다. 도면에 들어간 단가는 그 도면에 저장되어 나중에 단가표가 바뀌어도 그대로입니다.

3D 화면에서 물건을 눌러 고르면 끌어서 옮기고, 15°씩 돌리고, 복제·지우기·되돌리기를 바로 할 수 있습니다.
3D 화면의 ‘영상’(휴대폰은 ‘저장’)으로 **12초 한 바퀴 돌려 보기**, **동선 따라 걷기**, **지금 화면 녹화**를 동영상(mp4, 안 되면 webm)으로 저장합니다.

**현장 사진 핀**: ‘사진’ 도구로 도면의 그 자리를 누르고 사진을 찍거나 여러 장 고르면 번호 핀이 꽂힙니다 (안드로이드 앱은 ‘사진 찍기 / 사진첩에서 고르기’). 핀마다 제목·메모를 적고,
누르면 사진을 크게 넘겨 보며, 집계에 핀별 사진 수가 나옵니다.

**제안서 PDF** (파일 → 제안서, 또는 견적 화면의 ‘제안서 만들기’): 표지(3D 큰 그림·받는 분·면적·견적 합계 같은 핵심 숫자·인사말·
회사 정보와 로고), 3D 투시도(조감도·반대쪽·위에서), 평면도, 물량 집계, 견적서, 현장 사진을 A4 한 묶음으로 만들어 고객에게 바로 보냅니다.

앱 전체는 `www/` 폴더에 있습니다 (순수 HTML·CSS·JavaScript, 빌드 도구·외부 라이브러리 없음).

- 실행: `www/index.html`을 웹 서버로 엽니다. 예: `python3 -m http.server 8080 --directory www` → http://localhost:8080
  (파일을 브라우저로 바로 열어도 대부분 동작하지만, DWG 열기와 오프라인 설치는 웹 주소로 열었을 때만 됩니다)
- 휴대폰 홈 화면에 추가하면(PWA) 인터넷 없이도 열립니다.
- 안드로이드 앱 만들기: [docs/CAPACITOR.md](docs/CAPACITOR.md)
- 아이폰·아이패드에서 쓰기 (홈 화면 웹앱, Xcode로 아이폰 앱 빌드): [docs/IPHONE.md](docs/IPHONE.md)

| 경로 | 내용 |
|---|---|
| `www/index.html`, `css/style.css` | 화면 |
| `www/js/model.js`, `geom.js`, `rooms.js` | 도면 데이터, 기하, 방 인식 |
| `www/js/measure.js`, `catalog.js`, `summary.js` | 면적·자재·수량 계산, 벽 종류·프리셋·가구 목록, 집계표 |
| `www/js/joins.js`, `dims.js` | 벽 이음(T자·ㄱ자), 치수 자동 (안목·벽 중심·바깥) |
| `www/js/tools.js`, `snap.js`, `input.js`, `keys.js` | 그리기 도구, 스냅, 터치·마우스·키보드 |
| `www/js/draw.js`, `canvas.js` | 캔버스 그리기, 격자·눈금자 |
| `www/js/modes.js` | 두 모드(인테리어 도면 / 조감도)와 모드별 도구 줄 |
| `www/js/routes.js`, `images.js`, `photos.js` | 동선 길이·걸리는 시간·동선 체크, 넣은 이미지(현수막·벽보·현장 사진) 저장, 현장 사진 핀 번호·크게 보기 |
| `www/js/gl3d.js`, `models3d.js`, `view3d.js` | 3D 엔진(WebGL: 하늘·바닥 재질·그림자·글자 면), 물건·가구 모형, 조감도·걷기 화면, 영상 녹화, 제안서용 3D 그림 |
| `www/js/sprites.js` | 3D 모형을 화면 밖에서 그려 만든 물건 그림 (평면의 색 그림, 고르는 창의 미리보기) |
| `www/js/estimate.js`, `proposal.js` | 견적: 단가·금액·부가세, 견적서 PDF·CSV / 제안서 PDF (표지·3D·평면·집계·견적·사진) |
| `www/js/props.js`, `catalog-ui.js`, `settings.js`, `ui.js`, `edit.js` | 속성 패널, 목록 편집, 설정, 화면 구성, 편집 기능 |
| `www/js/storage.js`, `projects.js`, `export.js` | 자동 저장·도면 목록·백업, CSV·PNG·PDF 내보내기 |
| `www/js/dxf.js`, `dwg.js`, `dwg-worker.js`, `underlay.js` | DXF·DWG 불러오기와 밑그림 |
| `www/lib/libredwg/` | DWG 변환 모듈 (GNU LibreDWG, GPL v3) |
| `www/manifest.json`, `sw.js`, `icons/` | 홈 화면 설치·오프라인 |
| `android/`, `ios/` | 안드로이드 앱·아이폰 앱 프로젝트 (Capacitor 8) |
| `.github/workflows/ios-build.yml` | 아이폰 앱이 빌드되는지 GitHub의 맥에서 확인 (서명 없이) |

`index.html`(저장소 맨 위)은 이 앱과 별개인 기존 페이지입니다.
