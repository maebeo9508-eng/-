# 몽글타워 — 게임 기획서

> 잠들지 않는 고양이 모찌와 친구들이 백 층짜리 꿈의 탑을 오르는 **던전 액션 모바일 로그라이크**.
> 고른 주인공으로 무기를 직접 휘두르고, 방을 비우면 포탈로 다음 층으로. 층마다 강해지는 판타지 몬스터, 10층마다 바뀌는 던전, 매 판 달라지는 능력·아티팩트 조합.

- 플레이: `tower/index.html` (브라우저에서 바로 실행, 설치 불필요)
- 원작 소설: [`docs/novel/`](novel/README.md)
- 에셋: [`docs/ASSET_PLAN.md`](ASSET_PLAN.md) (AI 생성 계획), [`docs/ASSET_PROMPTS.md`](ASSET_PROMPTS.md) (제작 가이드)

## 1. 한 줄 요약과 핵심 재미

| 항목 | 내용 |
|---|---|
| 장르 | 탑다운 던전 액션 로그라이트 (세피리아 같은 무기 휘두르기 + 층 진행 로그라이크) |
| 플랫폼 | 모바일 세로 화면 우선, PC 브라우저 지원 |
| 한 판 | 5~20분. 쓰러지면 마을(야영지)로 돌아와 정비 후 재도전 |
| 핵심 재미 | ① 무기마다 다른 연속 공격을 직접 휘두르는 손맛 ② 12명의 주인공 — 능력치·고유 특성·필살기·주 무기가 다름 ③ 천천히 오르는 레벨업 능력과 아티팩트 조합 ④ 장비·보석·룬·특성으로 다음 판을 더 강하게 ⑤ 10층마다 새 던전과 보스, 구출한 친구가 새 주인공으로 |
| 차별점 | 모든 던전이 "악몽에 물든 마을 사람의 꿈". 보스를 이기면 그 사람이 깨어나 고를 수 있는 주인공이 되고, 소설 한 장이 열린다 |

### 게임 루프

```
[마을: 정비] ──출발──▶ [탑: 층 진행] ──쓰러짐/귀환──▶ [결과: 전리품 정산] ──▶ [마을]
   주인공 고르기            웨이브 전투 → 레벨업 능력 선택           골드·마석·별조각
   장비·보석·룬·특성        방을 비우면 포탈 → 걸어 들어가 다음 층     장비·룬·보석은 그대로 보관
   스킬·펫                 보물 방·보스에서 아티팩트                 
                          10층마다 보스 → 친구 구출 → 체크포인트
```

- **잃는 것**: 탑 안에서 고른 능력, 레벨, 아티팩트, 현재 층 위치
- **남는 것**: 주운 골드·장비·룬·보석·마석·별조각 전부 (모바일 캐주얼에 맞춰 관대하게)
- **체크포인트**: 보스를 처치한 층 다음부터 출발 가능 (1, 11, 21 … 91층)
- 탑에는 한 번에 한 명만 오를 수 있어요 (등불 빛은 한 사람만 감싸 줌). 나머지 친구는 야영지에서 차례를 기다려요

## 2. 조작 — 직접 움직이고 직접 휘두르기

| 입력 | 모바일 | PC |
|---|---|---|
| 이동 | 화면을 누른 자리에 생기는 조이스틱 | WASD / 방향키 |
| 공격 | 오른쪽 아래 ⚔️ 버튼을 **누르고 있는 동안 연속 공격** (가까운 적을 자동 조준) | 마우스 왼쪽 버튼 또는 J (마우스 쪽을 조준) |
| 대시 | 💨 — 잠깐 무적으로 빠르게 이동 | Space / Shift / 마우스 오른쪽 |
| 스킬 | 장착한 스킬 (쿨다운) | Q |
| 필살기 | 주인공 얼굴 버튼 — 때릴수록 게이지가 차고, 가득 차면 반짝여요 (컷인 + 슬로우) | E |
| 물약 | 🧪 체력 회복 | R |
| 일시정지 | ⏸ | Esc / P |

- 모든 적의 공격은 **예고 → 공격** 순서입니다. 돌진 전에는 하얀 선, 범위 공격 전에는 빨간 원, 레이저 전에는 조준선이 먼저 나타나요. 보고 피하거나 대시로 빠져나가는 게 실력입니다.
- 휘두르는 동안에는 이동이 조금 느려져요(근접 무기). 휘두르기와 구르기의 리듬이 핵심.
- 레벨업 선택은 레벨이 오른 순간 카드 창으로 나와요 (게임이 잠깐 멈춤).

## 3. 탑 구조

### 3.1 층과 방, 포탈

- 1층마다 하나의 방. 일반 전투방은 2~4개의 웨이브로 구성
- 웨이브의 적이 75% 이상 쓰러지면 다음 웨이브가 소환됨(템포 유지)
- 방의 몬스터를 모두 쓰러뜨리면 방 위쪽에 **포탈 2개**가 열려요. 포탈 위의 아이콘이 *다음 층의 방 종류*. 원하는 포탈 위로 **걸어 들어가면** 다음 층으로 (화면 밖이면 화살표로 알려 줌)

| 포탈 | 다음 방 | 보상 / 특징 |
|---|---|---|
| ⚔️ 전투 | 일반 웨이브 | 클리어 시 골드 묶음 |
| 💀 위험 | 웨이브 +1, 적 수 ×1.3, 엘리트 등장 | 장비 상자(희귀 이상) + 35% 아티팩트 |
| 🏺 보물 | 전투 없음 | **아티팩트 제단** (3개 중 1개) + 골드 |
| ⛲ 샘터 | 전투 없음 | 체력 45% 회복, 물약 +1, 🏠 귀환 포탈 |
| 🛒 상점 | 전투 없음 | 너굴 상점(수프·물약·능력 뽑기·장비 보따리·보석 주머니·아티팩트 1개) |
| ✨ 축복 | 전투 없음 | 희귀 능력 확률이 높은 능력 선택 |
| 👑 보스 | 9층 다음에 강제 | 스테이지 보스 |
| 🏠 마을로 | 보스 처치 후·샘터에서 | 전리품 챙겨 귀환 |

### 3.2 난이도 곡선

몬스터와 장비는 **같은 성장 곡선**을 따릅니다.

```
S(층) = 1.06^(층-1) × (1 + 0.02 × (층-1))
몬스터 체력 = 기본 체력 × S(층)        몬스터 공격력 = 기본 공격력 × S(층) × 1.35
장비 능력치 = 기본값 × S(아이템 레벨) × 등급 배율
```

| 층 | 10 | 20 | 30 | 50 | 70 | 100 |
|---|---|---|---|---|---|---|
| S(층) | 2.0 | 4.2 | 8.6 | 34 | 128 | 960 |

- 방어력은 층 기준 상대값: `피해 감소 = 방어력 / (방어력 + 30 × S(층))`, 최대 70%
- 적 수: `min(15, 4 + 층내순서×0.6 + 층/9)` (+위험방·끝없는 탑 보정)
- 스테이지가 오를수록 적 이동 속도 +2.5%, 적 탄환 속도 +3.5%씩 빨라짐
- 101층부터 **끝없는 탑**: 스테이지가 다시 순환하며 체력 ×1.25, 적 +2

### 3.3 레벨업 속도 (천천히)

`필요 경험치 = 8 + 레벨×7 + 레벨²×0.85` → 1→2: 16, 5→6: 64, 10→11: 156.
테스트 기준 1~10층에서 레벨 6~7 정도 (한 층에 레벨 하나가 안 될 만큼). 능력 하나하나가 더 소중해요.

## 5. 전투 시스템

### 5.1 무기 12종 — 휘두르는 방식이 전부 달라요

근접 무기는 **연속 공격(콤보)** 을 한 동작씩 재생해요. 칼날이 지나간 자리(쓸고 간 각도)에 있는 적만 맞고, 하얀 궤적이 남아요. 공격 버튼을 누르고 있으면 다음 동작으로 이어지고, 잠깐 쉬면 첫 동작부터.

| 무기 | 콤보 | 배율 | 특징 |
|---|---|---|---|
| 🗡️ 검 | 베기 → 되베기 → 돌진 찌르기 | 1.0 | 적의 탄환을 베어 냄 |
| ⚔️ 대검 | 큰 베기 ×2 → 회전 베기 | 1.65 | 느리지만 넓고 강한 넉백, 탄환 베기 |
| 🔪 단검 | 찌르기 ×2 → 베기 → 돌진 찌르기 | 0.5 | 아주 빠름, 치명타 +12% |

- 첫 실행: 프롤로그 대화 (할머니와 등불, 삐약이 부화, 무기를 든 털실 인형 셋이 깨어남, "번갈아 가며 오르자")
- 첫 출발: 조작 안내 (이동·공격 버튼·대시·스킬·필살기·포탈)
- 각 던전 첫 층: 입장 대사 / 보스 첫 만남: 보스 대사 / 첫 처치: 구출 대사 → 새 주인공 합류 → 소설 장 해금
- 마을 화면: 탑의 창문이 클리어한 스테이지만큼 노랗게 켜지고, 고른 주인공이 모닥불 앞에, 나머지 친구들은 둘레에서 쉬어요
- 결과 화면: "등불이 탑 아래로 데려다주었어요", "다른 친구로 올라가 보는 건 어때요?" 같은 대사

## 9. 기술 구조

순수 HTML5 Canvas + 바닐라 JS. 빌드 도구 없이 `index.html` 을 열면 실행됩니다.

```
tower/
  index.html            진입점
  css/style.css         스티커 스타일 UI
  assets/manifest.js    PNG 에셋 등록 (손으로). manifest.auto.js 는 가져오기 도구가 자동 작성
  assets/asset-plan.json  AI 에셋 생성 계획 (프롬프트·동작·크기·크레딧)
  js/core/              유틸, 저장(옛 저장 자동 변환), 효과음(WebAudio 합성), 입력(조이스틱·공격 버튼·마우스 조준), 에셋 로더
  js/render/art.js      "몽글 아트 엔진" — look 데이터로 모든 생물·무기 12종·장애물을 그림 (고블린 귀·해골 눈·엄니·두건·뿔투구·거미 다리·망토·손에 든 무기…)
  js/render/fx.js       파티클, 피해 숫자, 화면 흔들림
  js/render/scene.js    탑 장면(어둠·횃불 빛·포탈 화살표) / 마을 장면 / 초상화·아이콘 캐시
  js/data/              던전, 몬스터, 장비·보석, 룬, 스킬·능력, 아티팩트, 주인공·펫·특성, 대사, 소설(자동 생성)
  js/game/              능력치, 전리품, 방 생성(돌바닥·벽돌 벽), 전투, AI, 보스, 펫, 주인공 필살기, 플레이어(휘두르기 엔진), 런 진행
  js/ui/                공용 모달·대화, HUD(행동 버튼), 마을 화면
  tools/                build-novel.js · build-asset-plan.js · export-refs.js · import_sprites.py · gallery.html · sprite-packer.html
```

- 휘두르기 엔진: 무기의 combo(arc·thrust·spin·smash·whip)를 한 동작씩 재생. 매 프레임 쓸고 간 각도 안의 적만 맞히고, 하얀 초승달 궤적과 무기 그림을 함께 그려요
- 그림체: **귀여운 동물 주인공 + 판타지 던전 몬스터 + 도트 감성**. 도트 감성 화면은 월드를 작은 캔버스에 그린 뒤 픽셀 그대로 확대 (글자·체력바는 선명하게). 설정에서 끌 수 있어요
- 동작 재생: 반복(idle·walk) + 한 번 재생(attack·hurt·ult·cast·die)
- 저장: `localStorage` (`mongle_tower_save_v1`). 저장이 막힌 환경에서도 메모리로 플레이 가능
- 테스트용 주소: `tower/index.html?dev` → 자원·주인공 전원·체크포인트 90층 지급 (개발 확인용)
