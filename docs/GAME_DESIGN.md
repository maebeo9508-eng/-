# 몽글타워 — 게임 기획서

> 잠들지 않는 고양이 모찌가 백 층짜리 꿈의 탑을 오르는 **모바일 탑다운 로그라이크**.
> 귀엽고 단순한 조작, 층마다 강해지는 적, 10층마다 바뀌는 세계, 그리고 매 판 달라지는 성장.

- 플레이: `tower/index.html` (브라우저에서 바로 실행, 설치 불필요)
- 원작 소설: [`docs/novel/`](novel/README.md)
- 에셋 제작 가이드(ChatGPT · Gemini): [`docs/ASSET_PROMPTS.md`](ASSET_PROMPTS.md)

## 1. 한 줄 요약과 핵심 재미

| 항목 | 내용 |
|---|---|
| 장르 | 탑다운 액션 로그라이트 (아처리오·뱀서류의 자동 공격 + 층 진행) |
| 플랫폼 | 모바일 세로 화면 우선, PC 브라우저 지원 |
| 한 판 | 5~20분. 쓰러지면 마을(야영지)로 돌아와 정비 후 재도전 |
| 핵심 재미 | ① 한 손 조작으로 피하면서 자동 공격 ② 레벨업마다 고르는 능력 조합 ③ 장비·룬·특성으로 다음 판을 더 강하게 ④ 10층마다 새 세계와 보스, 구출한 동료 |
| 차별점 | 모든 층이 "잠든 마을 사람의 꿈". 보스를 이기면 그 사람이 깨어나 동료가 되고, 소설 한 장이 열린다 |

### 게임 루프

```
[마을: 정비] ──출발──▶ [탑: 층 진행] ──쓰러짐/귀환──▶ [결과: 전리품 정산] ──▶ [마을]
   장비 장착·강화          웨이브 전투 → 레벨업 능력 선택          골드·보석·별조각
   룬·특성·스킬            문 2개 중 하나 선택 → 다음 층          장비·룬은 그대로 보관
   펫·동료 선택            10층마다 보스 → 동료 구출 → 체크포인트
```

- **잃는 것**: 탑 안에서 고른 능력, 레벨, 현재 층 위치
- **남는 것**: 주운 골드·장비·룬·보석·별조각 전부 (모바일 캐주얼에 맞춰 관대하게)
- **체크포인트**: 보스를 처치한 층 다음부터 출발 가능 (1, 11, 21 … 91층)

## 3. 탑 구조

### 3.1 층과 방

- 1층마다 하나의 방. 일반 전투방은 2~4개의 웨이브로 구성
- 웨이브의 적이 75% 이상 쓰러지면 다음 웨이브가 소환됨(템포 유지)
- 방을 비우면 **문 2개**가 열리고, 문에 그려진 아이콘이 *다음 층의 방 종류*를 알려 줌

| 문 | 다음 방 | 보상 / 특징 |
|---|---|---|
| ⚔️ 전투 | 일반 웨이브 | 클리어 시 골드 묶음 |
| 💀 위험 | 웨이브 +1, 적 수 ×1.3, 엘리트 등장 | **장비 상자(희귀 이상)** |
| 🎁 보물 | 전투 없음 | 보물 상자 + 골드 |
| ⛲ 샘터 | 전투 없음 | 체력 40% 회복, 물약 +1, 🏠 귀환 문 |
| 🛒 상점 | 전투 없음 | 너굴 상점(수프·물약·능력 뽑기·장비 보따리) |
| ✨ 축복 | 전투 없음 | 희귀 능력 확률이 높은 능력 선택 |
| 👑 보스 | 9층 다음에 강제 | 스테이지 보스 |
| 🏠 마을로 | 보스 처치 후·샘터에서 | 전리품 챙겨 귀환 |

전투 없는 방은 안전하지만 경험치를 못 얻으므로 **"안전 vs 성장"** 의 선택이 생깁니다.

### 3.2 난이도 곡선

몬스터와 장비는 **같은 성장 곡선**을 따릅니다.

```
S(층) = 1.06^(층-1) × (1 + 0.02 × (층-1))
몬스터 체력 = 기본 체력 × S(층)        몬스터 공격력 = 기본 공격력 × S(층) × 1.35
장비 능력치 = 기본값 × S(아이템 레벨) × 등급 배율
```

| 층 | 10 | 20 | 30 | 50 | 70 | 100 |
|---|---|---|---|---|---|---|
| S(층) | 2.0 | 4.2 | 8.6 | 34 | 128 | 960 |

- 탑 안에서 얻는 능력(레벨업)은 한 판 안에서 약 ×2~3배 성장 → 같은 장비로 10~20층 더 버티면 벽에 부딪힘
- 벽을 넘는 방법: 그 층 수준의 장비, 높은 등급, 강화(+7%/단계, 최대 +20), 룬·특성
- 방어력은 층 기준 상대값: `피해 감소 = 방어력 / (방어력 + 30 × S(층))`, 최대 70%
- 적 수: `min(15, 4 + 층내순서×0.6 + 층/9)` (+위험방·끝없는 탑 보정)
- 스테이지가 오를수록 적 이동 속도 +2.5%, 적 탄환 속도 +3.5%씩 빨라짐
- 101층부터 **끝없는 탑**: 스테이지가 다시 순환하며 체력 ×1.25, 적 +2

## 6. 정비(마을) 시스템

### 6.1 장비 — 5부위 × 10테마 × 4종 + 무기 7종 + 고유 장비 16종

- 부위: 무기 · 모자 · 옷 · 신발 · 장신구
- 이름 = 테마(스테이지) + 종류: 「쿠키 검」, 「고드름 투구」, 「별빛 로브」, 「태엽 방울」 …
- 등급 6단계

| 등급 | 색 | 배율 | 랜덤 옵션 | 비고 |
|---|---|---|---|---|
| 일반 | 회색 | 1.0 | 0 | |
| 고급 | 초록 | 1.25 | 1 | |
| 희귀 | 파랑 | 1.55 | 2 | |
| 영웅 | 보라 | 1.95 | 3 | |

| 신화 | 빨강 | 3.2 | 4 | 30층부터, 75% 확률로 고유 효과 |

- 부위 기본 능력치: 무기=공격력, 모자/옷=체력+방어력, 신발=체력+이동속도, 장신구=치명·치피·공속·골드 중 2개
- 종류별 성격: 투구(방어↑), 왕관(체력↑), 두건(+치명), 망토(+회피), 로브(+쿨감), 샌들(이속↑), 운동화(+회피), 부츠(+방어)
- 랜덤 옵션 20종: 공격%, 체력%, 방어%, 공속, 치명, 치피, 이속, 흡혈, 골드, 경험치, 쿨감, 보스 피해, 스킬 피해, 화상/둔화/번개/중독 확률, 재생, 회피, 펫·동료 피해
- 강화: 골드, 최대 +20, 단계당 기본 능력치 +7%
- 분해: 골드 환급 (일반·고급 일괄 분해)
- 탑 안 보물 상자에서 나온 장비는 **그 자리에서 바로 장착** 가능

### 6.2 룬 — 14종 × 5등급, 합성

- 슬롯 6개: 처음 2개, 짝수 스테이지 보스 첫 처치마다 +1, 또는 보석으로 개방
- **같은 종류·같은 등급 3개 → 한 등급 위** ("모두 합성하기" 한 번에)
- 종류: 힘, 생명, 수호, 신속, 바람, 예리함, 파괴, 흡혈, 불꽃, 서리, 번개, 행운, 지혜, 시간
- 획득: 엘리트·보스·보물 상자, 상점 룬 주머니. 30층+에서 2등급, 70층+에서 3등급 드롭

### 6.3 특성 — 별조각으로 배우는 영구 성장 (3갈래 × 5노드)

## 9. 기술 구조

순수 HTML5 Canvas + 바닐라 JS. 빌드 도구 없이 `index.html` 을 열면 실행됩니다.

```
tower/
  index.html            진입점
  css/style.css         스티커 스타일 UI
  assets/manifest.js    PNG 에셋 등록 (비어 있으면 코드로 그린 그림 사용)
  js/core/              유틸, 저장, 효과음(WebAudio 합성), 입력, 에셋 로더
  js/render/art.js      "몽글 아트 엔진" — look 데이터로 모든 생물/무기/장애물을 그림
  js/render/fx.js       파티클, 피해 숫자, 화면 흔들림
  js/render/scene.js    탑 장면 / 마을 장면 / 초상화·아이콘 캐시
  js/data/              스테이지, 몬스터, 장비, 룬, 스킬, 펫·동료·특성, 대사, 소설(자동 생성)
  js/game/              능력치, 전리품, 방 생성, 전투, AI, 보스, 아군, 플레이어, 런 진행
  js/ui/                공용 모달·대화, HUD, 마을 화면
  tools/build-novel.js  docs/novel → js/data/novel.js 변환
  tools/sprite-packer.html  AI 이미지 → 스프라이트 시트 변환 도구
```

- 저장: `localStorage` (`mongle_tower_save_v1`). 저장이 막힌 환경에서도 메모리로 플레이 가능
- 테스트용 주소: `tower/index.html?dev` → 자원·동료·체크포인트 90층 지급 (개발 확인용)
