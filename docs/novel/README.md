# 모찌와 백 층의 꿈 — 몽글탑 이야기

> 잠들지 못하는 하얀 고양이 모찌가, 꿈을 잃은 마을을 구하려고 백 층짜리 탑을 오르는 이야기.

게임 『몽글타워』의 원작 소설입니다. 게임 속 **📖 이야기** 메뉴에서도, 스테이지 보스를 물리칠 때마다 한 장씩 열어 읽을 수 있어요.

## 줄거리

구름보다 높은 몽글탑 꼭대기에서는 밤마다 꿈별 **루미**가 금빛 꿈가루를 뿌려, 솜구름 마을 사람들에게 꿈을 나눠 줍니다. 그런데 어느 밤, 꿈가루가 까맣게 물들고 마을 사람들은 모두 악몽 속에 갇혀 깨어나지 못하게 됩니다.

깨어 있는 건 태어나서 한 번도 잠을 자 본 적 없는 고양이 **모찌**와, 그날 밤 알에서 깨어난 병아리 **삐약이**뿐. 모찌는 솜솜 할머니가 건네준 "돌아오는 등불"을 들고 탑에 오릅니다. 등불이 꺼지지 않는 한, 쓰러져도 몇 번이고 탑 아래로 돌아올 수 있습니다.

탑의 열 층마다 펼쳐지는 세계는 잠든 마을 사람 한 명 한 명의 꿈입니다. 악몽에 비틀린 꿈의 주인(보스)을 이겨 내면, 그 사람이 깨어나 모찌의 동료가 됩니다. 그리고 꼭대기에 가까워질수록, 할머니가 숨겨 온 오십 년 전의 약속과 모찌가 잠들지 못하는 진짜 이유가 드러납니다.
