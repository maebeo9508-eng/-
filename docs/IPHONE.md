# 아이폰·아이패드에서 쓰기

아이폰에서 쓰는 방법은 두 가지입니다. **맥 없이 바로 쓰려면 1번**, 앱 스토어처럼 설치되는 진짜 앱이 필요하면 2번입니다.
두 방법 모두 기능은 안드로이드 앱과 같습니다 (조감도·인테리어, 3D, 걷기, 집계·견적, PNG·PDF·CSV 저장, 백업).

| | 1. 홈 화면 웹앱 (추천) | 2. 아이폰 앱 (Xcode로 빌드) |
|---|---|---|
| 필요한 것 | 아이폰 사파리, 앱 주소 하나 | 맥, Xcode, 애플 계정 |
| 비용 | 없음 | 내 폰에만: 없음 (7일마다 다시 설치) / 동료에게 나눠 주기: 애플 개발자 등록 연 99달러 |
| 설치 | 사파리 → 공유 → 홈 화면에 추가 | Xcode에서 실행, 또는 TestFlight·앱 스토어 |
| 업데이트 | 새 버전을 올리면 다음에 열 때 자동으로 바뀜 | 다시 빌드해서 설치 |
| 인터넷 | 처음 한 번만 필요, 그 뒤로는 없어도 열림 | 필요 없음 |

## 1. 홈 화면 웹앱 (맥 필요 없음)

### 1-1. 앱 주소 만들기 (한 번만)

앱 전체가 `www/` 폴더에 있으므로, 이 폴더를 HTTPS 주소로 올리면 됩니다.
이 저장소는 이미 **GitHub Pages**가 켜져 있어 `https://maebeo9508-eng.github.io/-/` 에서 맨 위 `index.html`(초성 변환기)이 열립니다.

- **작업 브랜치를 `main`에 합치면** (Pull Request → Merge) 앱 주소가 바로 생깁니다.
  맨 위 `index.html`은 그대로라서 초성 변환기 주소는 바뀌지 않습니다.

  **앱 주소: `https://maebeo9508-eng.github.io/-/www/`**

- 합치지 않고 쓰려면: 저장소 **Settings → Pages → Branch**에서 작업 브랜치(`ccr-bc8f133f-omiyok`)와 `/ (root)`를 고르고 Save.
  (맨 위 `index.html`은 두 브랜치가 같습니다.)
- GitHub 말고 다른 곳에 올려도 됩니다. 예: https://app.netlify.com/drop 에 `www` 폴더(또는 PC용 묶음 안의 `app` 폴더)를 끌어다 놓으면
  1분 안에 주소가 나옵니다.

저장소 맨 위의 `.nojekyll` 파일은 GitHub Pages가 파일을 고치지 않고 그대로 올리게 하는 빈 파일입니다. 지우지 마세요.

### 1-2. 아이폰에 설치

1. 아이폰 **사파리**로 앱 주소를 엽니다. (크롬·카톡 안 브라우저 말고 사파리)
2. 처음 열면 안내 창이 뜹니다. 아래쪽의 **공유 버튼(네모에 화살표)** → **홈 화면에 추가** → **추가**.
3. 이제 홈 화면의 **현장도면** 아이콘으로 엽니다. 주소창 없이 전체 화면으로 열리고, 인터넷이 없어도 됩니다.

동료에게는 앱 주소만 카톡으로 보내면 됩니다. 안드로이드 동료는 APK를 쓰거나 같은 주소를 크롬으로 열어도 됩니다.

### 1-3. 알아 둘 점

- **파일 저장**(집계표 CSV, 도면 PNG·PDF, 3D 사진, 백업): 공유 창이 뜹니다. **파일에 저장**을 고르면 ‘파일’ 앱에,
  카톡·메일로 바로 보낼 수도 있습니다. 그림은 **이미지 저장**으로 사진첩에 넣을 수 있습니다.
- **파일 불러오기**(DWG·DXF, 백업): ‘파일’ 앱이 열립니다. 카톡으로 받은 파일은 먼저 ‘파일에 저장’ 해 두세요.
- **도면 저장 위치**: 아이폰 안에 저장됩니다. 사파리 탭으로만 쓰면 오래(7일 넘게) 열지 않을 때 iOS가 저장한 것을 지울 수 있으니
  **꼭 홈 화면 앱으로 쓰세요.** 홈 화면 앱은 따로 보관됩니다. 중요한 도면은 그래도 **파일 → 백업 저장**으로 받아 두세요.
- 사파리 탭과 홈 화면 앱은 저장소가 따로라서, 사파리에서 그린 도면은 백업 → 불러오기로 옮깁니다.
- **새 버전**: 주소에 새 파일을 올리면 다음에 열 때 받아 두었다가, 한 번 더 열 때 바뀝니다 (‘앱이 새 버전으로 바뀌었습니다’ 알림).

## 2. 아이폰 앱 (Xcode로 빌드)

`ios/` 폴더에 아이폰 앱 프로젝트가 들어 있습니다 (Capacitor 8, iOS 15 이상, 아이폰·아이패드).
앱 이름 `현장도면`, 번들 ID `kr.hyeonjang.domyeon` (안드로이드와 같음), 아이콘·시작 화면, 사진·카메라 권한 문구까지 넣어 두었습니다.
빌드는 **맥에서만** 됩니다 (애플 정책).

### 2-1. 준비 (맥)

1. **Xcode** (앱 스토어에서 설치, 16 이상)
2. **Node.js** LTS — https://nodejs.org
3. 이 저장소를 받고 폴더에서:

```bash
npm install
npx cap sync ios      # www/ 를 앱 안으로 복사 (웹 파일을 고칠 때마다 다시)
npx cap open ios      # Xcode가 열림
```

### 2-2. 내 아이폰에 설치 (무료)

1. 아이폰을 맥에 케이블로 연결하고, 아이폰 **설정 → 개인정보 보호 및 보안 → 개발자 모드**를 켭니다.
2. Xcode 왼쪽에서 **App** → **Signing & Capabilities** → **Team**에서 내 애플 계정을 고릅니다
   (없으면 Add an Account…). 번들 ID가 겹친다고 하면 `kr.hyeonjang.domyeon` 뒤에 `.내이름` 같은 것을 붙이세요.
3. 위쪽 기기 목록에서 내 아이폰을 고르고 ▶(Run).
4. 처음 한 번은 아이폰 **설정 → 일반 → VPN 및 기기 관리**에서 내 개발자 앱을 ‘신뢰’ 합니다.

무료 계정으로 설치한 앱은 **7일 동안** 쓸 수 있고, 그 뒤에는 다시 ▶ 하면 됩니다. 도면은 그대로 남습니다.

### 2-3. 동료에게 나눠 주기 (유료)

애플 개발자 프로그램(연 99달러, https://developer.apple.com/programs/)에 가입하면

- **TestFlight**: Xcode → Product → Archive → Distribute App → App Store Connect. 동료는 TestFlight 앱으로 초대 링크를 받아 설치 (90일마다 새 빌드).
- **앱 스토어** 정식 등록도 같은 길로 합니다 (심사 1~3일).

버전은 Xcode의 **General → Version / Build**에서 올립니다 (지금 2.9.0 / 19, 안드로이드와 맞춤).

### 2-4. 고친 뒤 다시 넣기

`www/` 파일을 고친 뒤에는 `npx cap sync ios` 를 다시 하고 Xcode에서 ▶ 합니다.
아이콘·시작 화면을 바꾸려면 `assets/` 의 그림을 바꾸고 `npx @capacitor/assets generate --ios`.

## 안드로이드 ↔ 아이폰 도면 옮기기

어느 쪽이든 **파일 → 백업 저장 (파일)** 로 만든 `.json` 파일을 카톡·메일로 보내고, 받는 쪽에서 **파일 → 백업 불러오기 (파일)**.
