# 에셋 폴더

- `sprites/` — 캐릭터·몬스터·펫·동료·보스 스프라이트 시트 (가로 한 줄, 프레임 256×256 권장)
- `icons/` — 스킬·장비 아이콘, 장애물, 바닥 타일, 로고
- `manifest.js` — 여기에 등록한 PNG만 게임이 불러옵니다. 등록하지 않은 것은 코드로 그린 기본 그림이 쓰여요.

만드는 방법은 [`docs/ASSET_PROMPTS.md`](../../docs/ASSET_PROMPTS.md), 시트로 묶는 도구는 [`tools/sprite-packer.html`](../tools/sprite-packer.html) 을 보세요.
